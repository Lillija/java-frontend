About This Blog

This is a simple blog built with vanilla JavaScript. It talks to the Laravel REST API (https://github.com/zirodev23/laravel-api) using AJAX, so the page never reloads. All content is rendered with DOM manipulation.

Two interchangeable AJAX techniques are implemented for exactly the same tasks: XMLHttpRequest with Promises and the Fetch API with async/await. Switch between them in the toolbar and repeat any action.

SSR, CSR and Hydration

SSR — Server-Side Rendering

The HTML is built on the server and sent complete. Great for the first paint and SEO, but every interaction needs the server.

CSR — Client-Side Rendering

The browser downloads a small shell and builds the DOM with JavaScript (like this page). Fast interactions, but the first paint waits for JS.

Hydration

The step where the framework takes the server-rendered HTML and attaches event listeners and state to it, making the static markup "come alive".
